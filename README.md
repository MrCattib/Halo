# Add Halo 
1. Open this link: [Halo](https://discord.com/oauth2/authorize?client_id=1562518713943462010)
2. Select your server
3. Allow: Send Messages
4. Done
# Configure AutoHalo
1. To enable do this:  /autohalo enable: #selected-channel
2. To disable do this:  /autohalo disable #channel-you-enabled-before
# Notes 
**AutoHalo:**
* AutoHalo is manageable only if you got Administrator permission.
* AutoHalo can be enabled in one text channel per server.

**Halo:**
* Halo is runnable for everyone.
* Halo doen't have any configuration.
