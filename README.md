2. Select your server.
3. Allow the required permissions.
4. Done! 

# Configure AutoHalo

### Enable AutoHalo

Use `/autohalo` and select the `enable` option, then choose a text channel.

### Disable AutoHalo

Use `/autohalo` and select the `disable` option, then choose the channel where AutoHalo is currently enabled.

# Notes

**AutoHalo:**

- Only members with Administrator permission can enable or disable AutoHalo.
- AutoHalo can be enabled in only one text channel per server.
- AutoHalo automatically welcomes new members in the configured channel.

**Halo:**

- Anyone with access to the bot can use `/halo`.
- `/halo` does not require additional configuration.
