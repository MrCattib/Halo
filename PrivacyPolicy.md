# Halo respects your privacy.
1. Data collected: Halo stores Discord server IDs, configured channel IDs, and the user ID of the administrator who enabled AutoHalo.
2. Purpose: This information is used to configure AutoHalo and send welcome messages.
3. Storage: Configuration data is stored by the bot.
4. Sharing: Halo does not sell personal data.
5. Retention: Configuration data remains stored until AutoHalo is disabled or the data is otherwise deleted.
6. Changes: This policy may be updated at any time.
7. Contact: For privacy questions, contact the developer through Discord.

**By using Halo, you acknowledge this Privacy Policy.**
